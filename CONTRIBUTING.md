# Contributing

Bug reports and focused fixes are welcome.

## Bug reports

Search existing issues first. Include your client, Vencord version or commit, media type, where the problem appears, and exact reproduction steps. Use harmless test media and remove private information from screenshots and logs.

## Code changes

- Keep changes focused on one behavior.
- Follow the surrounding TypeScript and React style.
- Test from a current Vencord source checkout.
- Run `pnpm testTsc` and `pnpm build` before submitting the change.
- Describe your hands-on tests and name the client you used.

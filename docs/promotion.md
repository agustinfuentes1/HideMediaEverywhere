## Discord post

I made HideMediaEverywhere, a Vencord userplugin for hiding specific images, GIFs, and videos without hiding the rest of the message. It can recognize supported images when they show up again, works in places like chat and search, and has a drag-to-peek placeholder. It requires a Vencord source build. Demo and install steps: https://github.com/t6rtar/HideMediaEverywhere

## Reddit or forum post

**Title:** I made a Vencord userplugin that hides specific media everywhere it appears

HideMediaEverywhere adds context-menu actions for hiding an image, GIF, video, or a message's media attachments. The plugin leaves the message visible and covers matching media with a placeholder in chat, search results, previews, and the GIF picker. You can drag the placeholder down to peek or choose a custom placeholder image.

The plugin requires building Vencord from source. The README has the demo, install steps, update instructions, and source:

https://github.com/t6rtar/HideMediaEverywhere
